01 / PLAYER PROFILE

先懂玩家，
再谈内容。

我不是“只会刷游戏”的人，也不是“只会写文案”的人。我的优势在中间：知道玩家为什么留下，也知道内容怎么被看见。

我是况益帆，新余学院网络与新媒体专业 2027 届本科生。 过去半年，我在广州喜聚做游戏业务运营：核心经营 3 个、协助运营 3 个游戏短视频账号，也参与了公司 AI 内容工作台「喜聚创作台」的搭建。

我的工作方法很朴素：先判断这条内容对谁有用，再想它凭什么被点开，最后用数据决定下一条继续还是换向。 从传奇老玩家到二次元、从棋牌上分到乙女向，不同人群说不同的话——这是我做账号矩阵时最重要的体感。

我也把 AI 当成真正的生产工具：用 GPT 生成海报，用敏感词库守住内容底线，用情报中心提高选题命中率。 工具负责提速，判断力还是人的事。

  1. 01

    情报选题

    版本公告、TapTap、玩家评论三处交叉，判断“这事玩家会不会讨论”。

  2. 02

    脚本分镜

    前 3 秒给结论或冲突，中段给信息，结尾给动作；不把废话留在开头。

    口播稿 / 分镜表
  3. 03

    素材录制

    实机录屏、角色展示、版本对比；能实拍就不空口，能证明就不形容词。

    模拟器 / 实机 / 录屏
  4. 04

    剪辑包装

    节奏、字幕、音效、封面标题；移动端第一眼要能读懂，第二眼要有点击欲。

    剪映 / PR / Canva
  5. 05

    审核发布

    敏感词、风险点、标题合规先过一遍；踩版本节点，给内容一个被看见的理由。

    敏感词词库 / 发布后台
  6. 06

    数据复盘

    完播、互动、涨粉、评论关键词；下一条继续放大，还是及时换向。

    Excel / 后台数据
NOW SELECTED 情报选题

版本公告、TapTap、玩家评论三处交叉，判断“这事玩家会不会讨论”。

A

先定人，再定内容

同一个游戏，传奇老玩家和二次元玩家的关注点完全不同。账号人设不是装饰，是选题过滤器。

B

封面是第二次选题

用户先看到封面，再决定要不要给内容一次机会。标题给结论，封面给情绪，两者必须说同一件事。

C

复盘不是写周报

复盘要能回答“下一条做什么”。只看播放量不够，要看评论在问什么、哪一秒在掉人。
